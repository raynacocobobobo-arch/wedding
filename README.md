# 婚礼精选 H5
本仓库包含已上传的9款婚礼场景产品图片及静态网页。所有图片均为横版1600×1000 JPG，首页和作品列表不显示价格。

## 在线地址
https://raynacocobobobo-arch.github.io/wedding/

## 首次启用 GitHub Pages
1. 在本仓库顶部点击 **Settings**。
2. 左侧打开 **Pages**。
3. **Build and deployment** → **Source** 选择 **Deploy from a branch**。
4. **Branch** 选择 **main**，文件夹选择 **/(root)**，点击 **Save**。
5. 等待 GitHub Pages 显示站点已发布，再打开上面的网页地址。

## 结构
- `index.html`：完整页面（保留 Kiss 风格布局及9个产品分类）。
- `images/`：9张横版婚礼主视觉图片。

## 重要说明
这是展示用途的H5：咨询表单只支持复制咨询信息，尚未连接商家数据库、客服或自动发送服务。电话和微信等商家联系方式暂未配置。
